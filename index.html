About me

I'm a DevOps Engineer with 5 years of DevOps and 6+ years of production infrastructure experience. I like taking manual, fragile processes and turning them into automated, repeatable ones, so developers can ship with confidence and production stays calm.

I started in networking and VoIP, working with Linux servers, Cisco switches and telephony. That background still shapes how I work: I think about reliability and security from the network layer up. Today I design CI/CD pipelines, run Kubernetes workloads and manage AWS infrastructure as code with Terraform and Ansible.

I also mentor junior DevOps engineers, standardize CI/CD practices across teams, and publish free DevOps, AWS and Linux courses on YouTube.
